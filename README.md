# ImagePacker

Простая программа с одной кнопкой: пакетная стилизация фото по вашему промпту
через **Google Gemini** ("Nano Banana") или **OpenAI** (модели семейства
`gpt-image`) — на выбор.

> Раньше проект назывался Nano Banana Sender. Настройки и зашифрованные ключи
> из старой папки `%APPDATA%\NanoBananaSender` подхватываются автоматически
> при первом запуске.

## Как получить API-ключ

**Google Gemini:**
1. Откройте [Google AI Studio](https://aistudio.google.com/apikey).
2. Войдите тем же Google-аккаунтом, что и Workspace-подписка.
3. Нажмите "Create API key", скопируйте ключ.

**OpenAI:**
1. Откройте [platform.openai.com/api-keys](https://platform.openai.com/api-keys).
2. Нажмите "Create new secret key", скопируйте ключ.
3. Учтите: у OpenAI API-ключ и подписка ChatGPT Plus — разные вещи, оплата
   идёт отдельно, по факту использования (см. [openai.com/pricing](https://openai.com/pricing)).

Ключи вводятся прямо в программе (поле "API-ключ") и хранятся только
локально, в файле `%APPDATA%\ImagePacker\config.json`, **в зашифрованном
виде**, отдельно для каждого провайдера (см. раздел "Безопасность и
приватность" ниже). Никуда, кроме официального API выбранного провайдера,
они не отправляются.

Вставить ключ можно через `Ctrl+V`, правой кнопкой мыши → "Вставить" или
кнопкой "Вставить" рядом с полем — все три способа работают в любой раскладке
клавиатуры (в т.ч. русской, где в обычном Tkinter `Ctrl+V` иногда не
срабатывает).

## Использование

1. Запустите `ImagePacker.exe` (или `python app.py`, если Python уже
   установлен и вы не собирали .exe).
2. Выберите провайдера — Google Gemini или OpenAI. Поле ключа, список
   моделей и все подсказки переключаются вместе с ним; переключение не
   стирает то, что было введено для другого провайдера.
3. Вставьте API-ключ выбранного провайдера.
4. Выберите модель. Для Gemini: `gemini-3-pro-image`, `gemini-3.1-flash-image`,
   `gemini-2.5-flash-image`. Для OpenAI: `gpt-image-1`, `gpt-image-1-mini`
   (это единственные модели OpenAI, надёжно поддерживающие редактирование
   уже существующего фото по промпту — DALL·E 3, например, такое не умеет).
   Точные доступные вам названия программа запрашивает у API сама: при
   запуске (если ключ уже сохранён) и каждый раз, когда вы вводите или
   вставляете новый ключ. Кнопка "Обновить список" делает то же вручную.
5. Кнопкой "Обзор..." укажите папку с исходными фото (`input`).
   Папка для результатов подставится автоматически рядом
   (`<папка>_output`), при желании можно поменять.
6. Введите промпт — он применяется ко всем фото в папке за один прогон.
   Между прогонами промпт (и даже провайдер) можно менять и запускать заново.
7. Настройте паузу между запросами (по умолчанию 6 сек) — защита от
   rate limit. Точные лимиты зависят от тарифа и провайдера — для Gemini
   смотрите [AI Studio → Usage](https://aistudio.google.com/usage), для
   OpenAI — [platform.openai.com/usage](https://platform.openai.com/usage).
8. Нажмите "Старт". Прогресс и ошибки видны в журнале внизу окна.
   "Стоп" останавливает обработку после текущего файла.

Результаты сохраняются в output-папку с именами файлов, совпадающими с
исходными (расширение — `.png`, либо `.jpg` для Gemini, если он вернул именно
JPEG). Оригиналы в `input/` не изменяются.

## Сборка .exe из исходников

```bash
pip install -r requirements.txt
pip install pyinstaller
build.bat
```

Готовый файл появится в `dist\ImagePacker.exe`.

## Обработка лимитов запросов (rate limits)

Логика одинакова для обоих провайдеров:

- Между запросами всегда выдерживается пауза (настраивается в интерфейсе,
  по умолчанию 6 сек) — это защита от кратковременного (per-minute) лимита.
- При ошибке `429` (превышен лимит запросов) программа сама делает до 5
  повторных попыток с нарастающей паузой (6, 12, 18... сек, +случайный
  джиттер, максимум 90 сек между попытками) и только потом переходит к
  следующему файлу.
- Программа отличает кратковременное превышение лимита (per-minute — есть
  смысл подождать и повторить) от **исчерпания квоты/баланса**
  (у Gemini — суточная квота per-day, у OpenAI — `insufficient_quota`,
  закончились деньги на балансе) — во втором случае весь пакет
  останавливается сразу, без бессмысленных повторов на оставшихся файлах,
  с понятным сообщением в журнале.
- Временные ошибки сервера (5xx) и сетевые обрывы тоже обрабатываются
  повтором с паузой.
- Если модель отказалась генерировать изображение (например, промпт нарушает
  политику), в журнале появится соответствующая запись, и обработка идёт
  дальше по остальным файлам — это не ошибка лимита.
- Точные значения лимитов зависят от вашего тарифа/модели и провайдера — если
  429 возникают часто даже с большой паузой, проверьте фактическую квоту в
  [AI Studio → Usage](https://aistudio.google.com/usage) (Gemini) или
  [platform.openai.com/usage](https://platform.openai.com/usage) (OpenAI) и
  увеличьте паузу в интерфейсе программы.

## Безопасность и приватность

- **API-ключи никогда не пишутся на диск в открытом виде.** Оба ключа
  (Gemini и OpenAI хранятся независимо друг от друга) шифруются через
  Windows DPAPI (`CryptProtectData`) с привязкой к вашей учётной записи
  Windows на этом компьютере — расшифровать файл `config.json` может только
  тот же пользователь Windows на том же компьютере. Даже если файл
  скопировать на другой ПК или под другого пользователя, ключи из него
  прочитать не удастся.
- Файл конфигурации (`%APPDATA%\ImagePacker\config.json`) дополнительно
  ограничен правами доступа только для текущего пользователя.
- В коде нет мест, где ключи или содержимое фото логируются, кешируются на
  сторонних серверах или отправляются куда-либо, кроме официального
  эндпоинта выбранного провайдера по HTTPS (TLS) — Gemini
  (`generativelanguage.googleapis.com`, через официальный SDK `google-genai`)
  или OpenAI (`api.openai.com`, через официальный SDK `openai`).
- Программа не содержит телеметрии, аналитики и сетевых вызовов, кроме
  обращений к API выбранного провайдера.
- **Важно:** отправляя фото в Gemini или OpenAI, вы передаёте их на серверы
  соответствующей компании — они обрабатываются согласно
  [политике Google по Gemini API](https://ai.google.dev/gemini-api/terms) или
  [политике OpenAI](https://openai.com/policies/row-terms-of-use/)
  соответственно. Не загружайте фото с чужими лицами/личными данными без
  согласия людей на фото, если это требуется по применимому законодательству
  (например, если вы работаете с фото третьих лиц).
- Оригиналы (`input/`) программа не изменяет и никуда, кроме самого запроса
  к API, не передаёт — они читаются локально и остаются на диске как были.
